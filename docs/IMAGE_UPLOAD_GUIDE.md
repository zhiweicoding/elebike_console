# 文章编辑器图片上传使用指南

## 功能概述

文章编辑器已集成七牛云图片自动上传功能，可以避免大量 base64 图片数据存储到数据库导致的性能问题。

## 支持的上传方式

### 1. 工具栏上传 📁

1. 点击编辑器工具栏的**图片按钮**
2. 在弹出的文件选择器中选择图片
3. 等待上传完成
4. 图片自动插入到编辑器中

**支持格式：** PNG、JPG、JPEG、GIF、WEBP  
**大小限制：** 单张图片不超过 5MB

---

### 2. 复制粘贴上传 📋

1. 在其他地方复制图片（如截图工具、网页图片）
2. 在编辑器中按 `Ctrl+V` (Windows) 或 `⌘+V` (Mac)
3. 图片自动上传并插入

**适用场景：**
- 截图工具（微信截图、QQ截图、系统截图等）
- 从网页复制图片
- 从图片查看器复制

---

### 3. 拖拽上传 🖱️

1. 从文件管理器中选中图片
2. 拖拽到编辑器区域
3. 松开鼠标，图片自动上传并插入

---

### 4. 自动替换 Base64 🔄

当你从某些网页粘贴内容时，如果包含 base64 格式的图片，系统会自动检测并将其上传到七牛云，然后替换为 CDN 链接。

## 上传状态提示

### 上传中
- 编辑器显示："图片上传中，请稍候..."
- 编辑器暂时锁定，无法编辑

### 上传成功
- 提示："图片上传成功"
- 图片显示在编辑器中

### 上传失败
- 提示："图片上传失败，请重试"
- 可能的原因：
  - 图片格式不支持
  - 图片大小超过 5MB
  - 网络连接问题
  - 服务器问题

## 提交前检查

在点击"提交"按钮时，系统会自动检查文章内容：

- ✅ **通过检查**：所有图片已上传，可以提交
- ❌ **无法提交**：存在未上传的图片，提示："文章中存在未上传的图片，请等待所有图片上传完成后再提交"

**解决方法：**
1. 等待所有图片上传完成
2. 检查是否有上传失败的图片
3. 删除或重新上传失败的图片

## 常见问题

### Q1: 为什么我的图片上传失败？

**可能原因：**
1. **图片格式不支持** - 只支持 PNG、JPG、JPEG、GIF、WEBP
2. **图片太大** - 单张图片不能超过 5MB
3. **网络问题** - 检查网络连接
4. **服务配置问题** - 联系管理员

### Q2: 粘贴图片后没有自动上传？

**检查步骤：**
1. 确认你复制的是图片文件，不是图片路径
2. 等待几秒，系统可能正在处理
3. 查看是否有错误提示
4. 尝试重新复制粘贴

### Q3: 我可以同时上传多张图片吗？

**可以！** 支持以下方式：
- 工具栏上传：一次选择一张
- 拖拽上传：可以同时拖拽多张图片
- 粘贴上传：如果剪贴板包含多张图片，会依次上传

### Q4: 上传的图片会保存在哪里？

图片上传到七牛云对象存储，路径格式为：
```
https://your-cdn-domain.com/article/时间戳_随机字符串.扩展名
```

示例：
```
https://cdn.example.com/article/1704067200_abc123.png
```

### Q5: 如果上传过程中关闭了页面会怎样？

**不建议这样做！** 可能导致：
- 部分图片未上传完成
- 文章内容包含 base64 图片
- 提交时会被系统阻止

**建议：** 等待所有上传完成后再关闭页面

### Q6: 可以撤销上传的图片吗？

**可以！** 在编辑器中：
1. 选中已插入的图片
2. 按 `Delete` 或 `Backspace` 键删除
3. 图片从编辑器中移除（但文件仍保留在七牛云）

### Q7: 上传的图片会被压缩吗？

**前端不压缩**，上传的是原图。如果需要压缩，建议：
1. 使用专业的图片压缩工具（如 TinyPNG）预先处理
2. 联系管理员在七牛云配置图片处理规则

## 最佳实践

### ✅ 推荐做法

1. **优先使用截图工具 + 粘贴** - 最快捷
2. **图片上传前先压缩** - 提高加载速度
3. **使用合适的图片格式**：
   - 照片 → JPG（体积小）
   - 图标/透明图 → PNG
   - 动图 → GIF
4. **等待上传完成再提交** - 避免提交失败
5. **定期清理未使用的图片** - 节省存储空间

### ❌ 避免的做法

1. ❌ 不要上传超大图片（> 5MB）
2. ❌ 不要在上传过程中刷新页面
3. ❌ 不要直接粘贴网页链接（需要粘贴图片本身）
4. ❌ 不要使用不支持的格式（如 BMP、TIFF）

## 技术细节

### 图片存储路径规则
```
article/时间戳_随机字符串.扩展名
```

- **时间戳**：13位，精确到毫秒
- **随机字符串**：6位字母数字组合
- **扩展名**：保留原始文件扩展名

**示例：**
- `article/1704067200123_a1b2c3.png`
- `article/1704067200456_d4e5f6.jpg`

### 上传流程

```
1. 用户触发上传（点击/粘贴/拖拽）
   ↓
2. 前端验证文件类型和大小
   ↓
3. 向后端请求上传凭证（Token）
   ↓
4. 使用七牛云 SDK 直接上传到七牛云
   ↓
5. 上传成功后获取 CDN 链接
   ↓
6. 将图片 URL 插入编辑器
```

### 安全机制

1. **Token 机制**：使用临时上传凭证，不暴露密钥
2. **类型限制**：前端 + 后端双重验证文件类型
3. **大小限制**：限制单文件 5MB
4. **提交检查**：防止 base64 图片进入数据库
